# Project Governance

## Governance Cadence
- **Daily**: Standup (15 min) - delivery team
- **Weekly**: Status meeting (60 min) - EM, client lead, key stakeholders
- **Bi-weekly**: Deep dive (90 min) - EM, practice director, technical leads
- **Monthly**: Steering committee (60 min) - Executive sponsor, Managing Partner, Practice Director, EM

## Decision Rights (RACI)
| Decision | EM | Practice Director | Managing Partner | Client Sponsor |
|----------|----|-------------------|------------------|----------------|
| Scope changes <$25K | A/R | C | I | C |
| Scope changes $25-100K | R | A | C | C |
| Scope changes >$100K | R | C | A | C |
| Team composition | R | A | I | C |
| Schedule baseline | R | A | I | C |
| Budget baseline | R | A | I | C |
| Risk acceptance | R | A | C | I |
| Escalation to client exec | C | R | A | I |

## Documentation Requirements
- Project Charter (initiation)
- Weekly Status Report
- Risk Register (updated weekly)
- Change Request Log
- Decision Log
- Lessons Learned (closure)

## Phase Gates
1. **Initiation → Planning**: Charter approved, team onboarded
2. **Planning → Execution**: Baseline approved, risks mitigated
3. **Execution → Closure**: Deliverables accepted, knowledge transferred

## Risk Management
- Identify: Weekly risk identification in team meeting
- Assess: Probability × Impact matrix
- Mitigate: Owner, action, target date for each risk > Medium
- Monitor: Risk register reviewed at each governance meeting
- Escalate: Risks trending to High auto-escalate to Practice Director
