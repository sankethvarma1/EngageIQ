# Delivery Playbook

## Engagement Initiation
All engagements must follow the standard initiation process:
- Confirm scope and objectives with client stakeholder
- Assign engagement manager and core team
- Establish baseline budget and timeline
- Set up project governance cadence (weekly status, monthly steering)
- Define success criteria and KPIs

## Delivery Governance
Weekly status meetings with client delivery lead. Monthly steering committee with executive sponsor. 
Escalation path: Engagement Manager → Practice Director → Managing Partner.

## Quality Assurance
- Code reviews for all technical deliverables
- Peer review for advisory deliverables
- Client walkthroughs at key milestones
- Retrospectives at phase gates

## Change Management
All scope changes must be documented through formal change request process.
Impact assessment required for schedule, budget, and quality.
Approval authority: < $25K - EM, $25K-$100K - Practice Director, > $100K - Managing Partner.
